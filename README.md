# 공유 HTML 문서

이 저장소의 `main` 브랜치에 HTML 파일을 올리면 GitHub Pages가 자동으로 배포합니다.

- 공개 주소: `https://kheo1868-sudo.github.io/shared-html-docs/`
- 시작 문서: `index.html`
- 배포 정의: `.github/workflows/deploy.yml`

## 새 문서 배포

1. HTML 파일을 이 폴더 또는 하위 폴더에 추가합니다.
2. 파일에 비밀번호, API 키, 개인정보, 비공개 목회·상담 기록을 포함하지 않습니다.
3. `main`에 커밋하고 push하면 GitHub Actions가 사이트를 배포합니다.

예: `sermons/2026-09-message.html` 파일은 배포 후 아래 주소로 공유합니다.

`https://kheo1868-sudo.github.io/shared-html-docs/sermons/2026-09-message.html`
